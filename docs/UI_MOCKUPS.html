Mockup 2 — QueryStateWrapper: The loading/error/data states are handled by a single wrapper component, eliminating the 3-branch boilerplate repeated in 20+ pages.

Before (×20+ pages)

if (isLoading)
  return <Skeleton rows={6} />

if (isError)
  return <ErrorState
    retry={refetch} />

return (
  <div>
    {data.items.map(...)}
  </div>
)
→

After (1 component)

<QueryStateWrapper
  data={data}
  isLoading={isLoading}
  isError={isError}
  retry={refetch}
  rows={6}
>
  {(data) =>
    data.items.map(item =>
      <Row key={item.id}
           {...item} />
    )
  }
</QueryStateWrapper>

Code Pattern Optimisation

Before: 10+ lines × 30 mutations

const mutation = useMutation({
  mutationFn: (data) => nodesApi.update(id, data),
  onSuccess: () => {
    qc.invalidateQueries({
      queryKey: ['nodes']
    })
    toast('Node updated')
    onClose()
  },
  onError: (e) =>
    toast(e.message, 'error'),
})
→

After: 3 lines × 30 mutations

const mutation = useCrudMutation({
  fn: (data) => nodesApi.update(id, data),
  invalidate: ['nodes'],
  successMsg: 'Node updated',
  onDone: onClose,
})
✓ Auto-invalidates query cache
✓ Auto-shows toast (success/error)
✓ Auto-calls onDone callback
✓ Handles Optimistic updates (opt-in)
